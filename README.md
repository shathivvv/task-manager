# Task Manager

A simple task management web app built with HTML, CSS, and vanilla JavaScript.

## Features

- Add new tasks
- Prevent empty task submissions
- Mark tasks as completed or incomplete
- Delete tasks
- Dynamically update the task list
- Responsive styling for smaller screens

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Add, complete, or delete tasks.
